
===== Demo 8: Interactive chat with the child process =====
Type a message and press Enter. The child replies in upper case.
Type 'exit' (or press Ctrl+D) to finish.

[PARENT 1765] child replied: "HELLO FROM THE KEYBOARD"
message> [PARENT 1765] invalid input: empty message, type some text
